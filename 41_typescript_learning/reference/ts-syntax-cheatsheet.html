基本型別

string / number / boolean

最基本的三種型別標註，寫在變數或欄位名稱後面，用冒號分隔：名稱: 型別。

password: string
agreedTerms: boolean
出現於：src/types/registration.ts（Step1Account）

聯集型別（Union Type）：A | B

用直線 | 連接多個型別，代表「這個值可能是 A，也可能是 B」。最常見的組合是「某個型別或 null」，用來表示「這欄位可能還沒有值」。

idFront: string | null
出現於：src/types/registration.ts（Step2Upload）

字串字面值聯集（String Literal Union）

聯集型別的每一項不一定是型別名稱，也可以是具體的字串值本身。這種寫法常用來取代「只能是這幾種固定值之一」的情境。

export type StepKey =
  | 'step1Account'
  | 'step2Upload'
  | 'step3Info'
  // ...
出現於：src/types/registration.ts

宣告型別

interface

宣告一個「物件形狀」的名稱：這個物件應該有哪些欄位、每個欄位是什麼型別。宣告之後，別的地方就能用這個名稱來標註型別，不用每次都重寫一整包欄位定義。

export interface Step1Account {
  password: string
  email: string
  agreedTerms: boolean
}
出現於：src/types/registration.ts

type 別名

interface 只能命名物件形狀，type 什麼型別都能命名——包括一串字串字面值的聯集，用來表示「只能是這幾種固定值之一」。

export type StepKey =
  | 'step1Account'
  | 'step2Upload'
  | 'step3Info'
  // ...
出現於：src/types/registration.ts

匯入型別

import type

只匯入型別、不匯入可執行的程式碼。編譯成 JS 時整行會被刪掉。有兩種寫法：整行開頭加 import type，或在同一行 import 裡對單一名字加 type 修飾。

import type { StepKey } from '../types/registration'
import { createRouter, type RouteRecordRaw } from 'vue-router'
出現於：src/router/index.ts

主要參考：TypeScript Handbook: Everyday Types ／ Type-Only Imports and Export

查表與挖取型別

泛型（Generic）：Record<K, V>

尖括號 <...> 讓同一個型別定義可以填入不同型別重複使用。Record<K, V> 是內建泛型，代表「鍵是 K 型別、值是 V 型別的物件」。如果 K 是固定聯集（像 StepKey），物件會被要求剛好有這些鍵，一個不多一個不少。

注意：同一個聯集用在「值的位置」（例如 idFront: string | null）代表「這個位置只能是其中一個」；但用在 Record<K, V> 的鍵位置，代表 K 的每一個成員都各自展開成一個欄位，效果完全不同，不要用同一種直覺類推。

const stepComponents: Record<StepKey, RouteRecordRaw['component']> = { ... }
出現於：src/router/index.ts

Indexed Access Type：Type['key']

從既有型別裡「挖」出某個欄位本身的型別，語法長得像執行期取值，但作用在型別層級。常用來跟第三方套件的型別定義保持同步，不用手動重寫一份容易過期的型別。

RouteRecordRaw['component']
出現於：src/router/index.ts

主要參考：Utility Types — Record ／ Indexed Access Types

陣列與型別推斷

陣列型別：Type[]

型別名稱後面加 []，代表「一個陣列，每個元素都要符合這個型別」。

const routes: RouteRecordRaw[] = [ ... ]
出現於：src/router/index.ts

展開運算子 ...（純 JavaScript，非 TS 專屬）

在陣列字面值 [...] 裡把後面陣列的每個元素各自攤開放進來，不是把整個陣列當成一個元素塞進去。

[0, ...[1, 2, 3]]  // [0, 1, 2, 3]
出現於：src/router/index.ts

型別推斷（Inference）

不是每個地方都要手寫 : 型別。TypeScript 會從上下文（例如陣列本身的型別、賦值目標的型別）自動推出型別，並在對不上的時候報錯。

出現於：src/router/index.ts（.map() 回呼裡沒寫任何型別標註）

主要參考：Everyday Types — Arrays ／ MDN: Spread Syntax
