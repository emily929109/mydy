
MemberSign2.cshtml（畫面）+ memberSign2.js（邏輯，Vue3 Options-less setup）共同組成「簽署約定書」流程。核心互動元件是 #sign_msg modal 內的兩層 canvas：

- #video-pad：畫出鏡頭畫面（含臉部，用來佐證本人操作）
- #signature-pad：透明疊圖層，SignaturePad 套件在上面接收手寫簽名

相機權限如何偵測

沒有用 navigator.permissions.query，而是直接嘗試呼叫 getUserMedia，靠 promise 的 then/catch 分流：

// memberSign2.js:384-398
const getCameraStream = video => {
    navigator.mediaDevices
        .getUserMedia(constraints)   // constraints = { audio:false, video:{facingMode:"user"} }
        .then(function success(stream) {
            showSignPad();            // 拿
            video.srcObject = stream;
        }).catch((err) => {
            computeToMobileSign();    // 被拒絕 / 無鏡頭 / 非HTTPS 等任何失敗 → 走轉手機簽署
        });
};Encrypt() 呼叫 /api/Member/EncryptByDES）跳到手機版繼續簽名。

觸發點是按下畫面上的「簽名」按鈕 → signButton() → 若有登入會員 → VideoInit()（memberSign2.js:521-543）初始化 canvas 尺寸並呼叫 getCameraStream(video)，同時用 requestAnimationFrame 的 getFrameFromVideo() 持續把 video 影格鏡像繪製到 canvas_video 上（左右翻轉，因為前鏡頭）。

memberSign2.js:290-379：

1. 檢查 signaturePad.isEmpty()，空的話 alert 阻擋。

 localStorage.member。
